# vokativ
Simple webpage for rewriting czech surnames to vokativ

## Pravidla

1. -a -> -o
2. -ž,š,č,ř,ď,ť,ň
    a. -ž,š,č,ř -> +i
    b. -ď,ť,ň -> d/t/n+i
3. -k,h,ch
    a. -> +u
    b. -ek -> -ku
4. -ec,(C)r -> e
    a. -ec -> -če
    b. (C)r -> (C)ře
5. -l,n,r
    a. -> +e
    b. -el -> -le
6. -e -> -e
7. Jinak nemenit

### Problemy

- j
- p Filip -> Filipe


### Doplnkove pravidla

1. Kraceni ve kmeni
2. Alternace ve kmeni

### Consonant

- Tvrdé h, Ch, k, R, d, T, n
- Měkké ž, š, č, ř, c, j, ď, ť, ň
- Obojetné b, F, L, m, p, s, v, z
